## Quick Start with Balsamiq Wireframes

1. **Get Balsamiq Wireframes** — Download the desktop app for Windows/Mac or open the web version directly in your browser.
2. **Launch** — Double-click the **Balsamiq Wireframes** icon. The project dashboard opens in under 3 seconds.
3. **Create your first wireframe** — Click “New Project” → drag a button or text field from the UI Library onto the canvas.
4. **Sketch a user flow** — Add multiple mockups and link them using the “Link to” feature in **Balsamiq Wireframes**. Click through your prototype to test navigation.
5. **Use UI components** — Explore the library of over 75 built-in controls: data grids, accordions, calendars, maps, and icons. Everything in **Balsamiq Wireframes** looks hand-sketched on purpose.
6. **Adjust (optional)** — Change the default sketchiness level, paper texture, or background color. Most people use **Balsamiq Wireframes** with default settings to preserve the low-fidelity focus.
7. **Export and share** — Export as PNG, PDF, or interactive HTML. **Balsamiq Wireframes** automatically saves your project so you never lose a single sketch.

## Understanding Balsamiq Wireframes Core Components

**Balsamiq Wireframes** is not just another diagramming tool. It combines several essential prototyping functions:

- **UI Library** with 75+ sketch-style controls — buttons, sliders, combo boxes, and advanced UI patterns like date pickers and tree navigators.
- **Interactive linking** — Turn static mockups into clickable prototypes without code using **Balsamiq Wireframes**.
- **Asset Manager** — Import and reuse your own icons, logos, and images while keeping the hand-drawn aesthetic.
- **Symbols and Masters** — Create a master UI element and update it across all pages instantly with **Balsamiq Wireframes**.
- **Quick Add** — Type what you need (e.g., “dropdown with three items”) and **Balsamiq Wireframes** places it on the canvas.
- **Markup and annotation tools** — Add arrows, sticky notes, callouts, and redlines to explain your thinking.
- **Export and presentation mode** — Full-screen presentations with clickable links and speaker notes inside **Balsamiq Wireframes**.
- **Project organization** — Group wireframes into folders, clone entire projects, and archive old iterations easily with **Balsamiq Wireframes**.

All these work together seamlessly in **Balsamiq Wireframes**. You never need to switch between separate design or diagramming applications.
